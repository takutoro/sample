## Amazon物販 商品リスト（`amazon-list.html`）

LINEグループチャットで共有されたAmazon商品リンクを抽出し、一覧として管理するためのページです。
サーバー不要の静的ページで、データはブラウザのlocalStorageにのみ保存されます（外部送信なし）。

### 使い方

1. LINEでグループトークを開く → メニュー「≡」→「その他」→「トーク履歴を送信」で `.txt` を保存
2. `amazon-list.html` を開き、`.txt` をドラッグ＆ドロップ（またはテキストを貼り付けて「取り込む」）
3. 抽出された商品に仕入値・売値・ステータス・メモを入力して管理
4. 「CSV出力」でExcel/スプレッドシートに書き出し

### できること

- LINEトーク履歴（Android形式 `2026/08/20(木)` / iPhone形式 `2026.08.20 木曜日`）のパース、複数行メッセージにも対応
- Amazonリンクの抽出とASIN判定（`/dp/`、`/gp/product/`、`/gp/aw/d/`、`/ASIN/`、`asin=` に対応。`amzn.asia` などの短縮URLはURL単位で管理）
- ASIN単位での重複マージ（誰が・いつ・何回共有したかを集計）。同じ履歴を再度取り込んでも二重登録されない
- メッセージ本文からの価格の自動読み取り（「仕入1,200円」「売値2,980円」「原価」「販売価格」など）
- 想定利益の自動計算：`売値 × (1 − 手数料率) − 仕入値`（手数料率は既定15%、画面上で変更可）
- 検索、ステータス／共有者での絞り込み、並び替え、CSV出力（Excelで文字化けしないUTF-8 BOM付き）
