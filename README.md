# sample

## Amazon物販 商品リスト（`amazon-list.html`）

LINEグループで共有されたASIN／Amazonリンクをリスト化し、**三重県鈴鹿市周辺の店舗ごとに在庫の有無と店頭価格を記録**するためのページです。
サーバー不要の静的ページで、データはブラウザのlocalStorageにのみ保存されます（外部送信なし）。

### 使い方

1. `amazon-list.html` を開く
2. 商品を取り込む
   - **「共有リストを読み込む」** … `shared-list.js` に登録済みの商品と、共有された店舗情報をまとめて取り込む
   - **ASINを貼り付け** … 共有されたASINを1行に1つ。`B0CXXXXXXX パナソニック 電動歯ブラシ` のように商品名を併記してもOK、AmazonのURLでもOK
   - **LINEトーク履歴** … トーク履歴の .txt をそのまま読み込ませる
3. 各商品の「店舗」ボタンで店舗チェックリストを開き、リサーチリンクで型番・JANを特定
4. 店頭で確認した結果（あり／なし・店頭価格・棚メモ）を記録
5. 「店舗別（巡回リスト）」に切り替えると、店舗ごとの「買う物リスト」になる
6. 「CSV出力」でExcel／スプレッドシートに書き出し

### できること

**リスト化**

- ASINの直接貼り付け（`B0`で始まる10桁）、Amazon URL、LINEトーク履歴（.txt）のいずれからも取り込み
- LINE本文中に直接書かれたASINも自動抽出。Android形式 `2026/08/20(木)` とiPhone形式 `2026.08.20 木曜日` に対応
- ASIN単位で重複マージし、**誰が・いつ・何回**共有したかを集計。同じ内容を再取り込みしても二重登録されない
- 本文中の「仕入1,200円」「売値2,980円」などの金額と、13桁のJANコードを自動で読み取り
- 想定利益 = `売値 × (1 − 手数料率) − 仕入値`（手数料率は既定15%、画面上で変更可）
- 検索、ステータス／共有者／店舗での絞り込み、並び替え、CSV出力（UTF-8 BOM付き）

**店舗リサーチ**

- 商品ごとに店舗チェックリスト（あり／なし／未確認・店頭価格・メモ）を記録
- 「最安店頭価格を仕入値に反映」で、店頭価格からそのまま利益計算
- 店舗別（巡回リスト）ビュー：店舗ごとに「その店に置いてある商品」を一覧化
- 商品ごとのリサーチリンク：Amazon商品ページ／ASINからの型番・JAN検索／Keepa／価格.com／楽天／Yahoo!ショッピング／メルカリ売切れ相場／Googleマップ
- JANコードを登録すると、取扱店検索・楽天・Yahoo!の各リンクがJAN検索に切り替わる
- 店舗マスタは自由に追加・削除可能

### 共有リスト（`shared-list.js`）

グループで共有された商品を蓄積するファイルです。ASIN・商品名・JAN・メモに加えて、
**「どの店舗で見かけたか」という共有情報**を `stores` に持たせられます。

```js
{
  asin: 'B0H7GMPZL6',
  name: '...',
  jan: '',
  memo: '...',
  stores: [
    // 実際に在庫が確認された店舗
    { id: 'yamada-suzuka', state: 'あり', memo: 'グループ共有：ヤマダ電機にあった' },
    // カテゴリから見て優先して回るべき店舗（在庫の主張はしない）
    { id: 'aeonmall-suzuka', state: '未確認', memo: '★優先：玩具売場' }
  ]
}
```

取り込み時、**自分で店頭確認した記録（未確認以外）は共有情報で上書きされません。**
何度読み込んでも重複しません。

### 制約

- **ASINから店舗の在庫を自動取得することはできません。** ASINはAmazon内部の識別子で、実店舗の在庫と紐づく公開データベースは存在しません（ASIN→JAN変換もSP-API等が必要）。本ツールはリサーチリンクで型番・JANを特定し、店頭で確認した結果を記録・共有する運用を支援するものです。
- `amzn.asia` などの短縮URLはブラウザから展開できないため、ASINは取得できずURL単位で管理します。
- 商品名はAmazonから自動取得できません。取り込み時のメッセージ本文を初期値とし、手動で編集できます。
